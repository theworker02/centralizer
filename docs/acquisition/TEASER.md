# Teaser — Centralizer

**One line:** One local-first runtime that discovers, connects, supervises, and calls software across languages through a unified protocol — without pretending detect-only adapters can `Call`.

## Why an acquirer cares

Polyglot systems accumulate ad-hoc bridges. Centralizer ships a **Go hub**, a documented **Protocol 1.x**, a **supervisor** with recovery/circuit breaking, and **honest adapter tiers**: Go / Python / Node / Rust have tested invocation paths today; other languages remain detect-only until Call is proven.

## What ships now (v0.1.x)

- `centralizer` / `centralizerd` binaries
- CIR + bridge planner
- stdio transport + policy/lockfile surfaces
- Tier-1 Call demos: `examples/go-python`, `examples/go-node`, `examples/go-rust`
- Acquisition data room under `docs/acquisition/`

## What this is not

- Not a claim that every language under `adapters/` can `Call`
- Not a hosted multi-tenant SaaS
- Not an asking price (none published)
