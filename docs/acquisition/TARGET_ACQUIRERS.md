# Target acquirers — Centralizer

**Date:** 2026-09-21  
**Status:** Strategic prospect list for outreach qualification. Not a claim of inbound interest.

## Fit thesis

Buyers who already sell **developer platforms**, **AI agent runtimes**, **iPaaS / automation**, or **polyglot observability** and need a **supervised local bridge** with an explicit protocol rather than another YAML-only orchestrator.

## Wave 1 themes (illustrative categories)

| Theme | Why Centralizer |
| --- | --- |
| Cloud / PaaS developer experience | Local polyglot stubs + supervised processes beside existing CLIs |
| AI coding agents / tool runtimes | Language-neutral Call surface with quarantine and policy |
| Integration / iPaaS | Process adapters instead of only HTTP connectors |
| Security / runtime isolation vendors | Supervisor, breaker, path policy, localhost-default daemon |
| Observability / OpenTelemetry adjacent | Hub metrics hooks + process lifecycle signals |

## Qualification filters

- Needs **local-first** or air-gapped bridge (not only cloud RPC)
- Willing to accept **early (v0.1)** maturity with clear Tier-1 vs detect-only roadmap
- Counsel can diligence **Apache → proprietary** history on prior tags

## Explicit non-targets (near term)

- Buyers requiring full JVM/.NET/`Call` on day one without roadmap funding
- Buyers seeking fabricated adoption metrics
