# Acquisition Brief — Centralizer

**Date:** 2026-09-21  
**Status:** Briefing document only. **No acquisition has occurred** by virtue of this file.

## What the project does

Interop runtime that discovers, connects, supervises, and exposes software across languages via a unified protocol/hub.

## Problem

Polyglot systems lack a supervised, local-first bridge with a documented protocol and adapter matrix.

## Included / excluded

Included (typical): repository, original Go code, protocol docs, adapters, brand assets created for the project, data room.  
Excluded: historical Apache grants on prior tags, dependency code, buyer infrastructure, unverified trademark registrations.

## Maturity / deployment / differentiation

Early (v0.1.x). Tier-1 call path for Go/Python/Node/Rust protocol speakers; many languages detect-only.

`make build` → bin/centralizer, bin/centralizerd; optional website; adapters need host runtimes.

Polyglot hub with explicit detect-vs-call honesty and localhost-default daemon.
